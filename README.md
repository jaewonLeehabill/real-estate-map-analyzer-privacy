## 1. 제품과 적용 범위

이 방침은 부동산 지도 화면에서 사용자가 선택한 영역의 매물 정보를 로컬로 정리하고 HTML·CSV·PNG 파일로 내보내는 Chrome 확장 프로그램에 적용됩니다.

## 2. 처리하는 데이터

확장 프로그램은 사용자가 지원 사이트에서 직접 수집을 시작한 경우, 해당 기능 제공에 필요한 범위에서 다음 정보를 읽고 처리할 수 있습니다.

- 현재 페이지 주소와 지도 상태
- 화면에 표시된 매물 번호, 위치·유형, 거래유형, 가격, 면적, 층, 방향, 사용승인일, 확인일, 관리비, 융자금, 매물 설명 및 중개사·정보제공처 표시
- 사용자가 선택한 지도 영역과 해당 영역의 화면 캡처
- 사용자가 입력한 메모, 필터·열·지도 표시 설정
- 수집 진행 상태, 실패 복구용 백업과 최소화된 진단 정보

지원 사이트 화면에 계정 정보가 있더라도 확장 프로그램은 계정 정보를 수집 대상으로 사용하지 않습니다. 지도 요소를 확실히 찾지 못한 전체화면 캡처는 중단하며, 진단 정보에 상세 화면 원문이나 전화번호를 저장하지 않도록 제한합니다.

## 3. 사용 목적

처리한 데이터는 사용자가 요청한 다음 기능에만 사용합니다.

- 선택 영역의 매물 정리와 비교표·히트맵·지도 라벨 생성
- 정렬·필터·메모와 로컬 누적 저장
- HTML·CSV·PNG 파일 생성
- 중단·실패 후 로컬 복구

광고, 사용자 추적, 신용평가, 데이터 판매 또는 제3자 마케팅에 사용하지 않습니다.

## 4. 저장 위치와 외부 전송

- 결과, 설정, 지도 이미지와 복구 데이터는 사용자의 Chrome 확장 프로그램 로컬 저장소(`chrome.storage.local`)에 저장됩니다.
- 사용자가 내보내기를 선택하면 파일은 사용자의 브라우저 다운로드 위치에 저장됩니다.
- 이 버전에는 회원가입·로그인·클라우드 저장·원격 분석·오류 자동 전송 기능이 없습니다.
- 확장 프로그램이 처리한 사용자 데이터는 개발자 서버나 광고·분석 서비스로 전송되지 않습니다.
- 원본 지원 사이트는 사용자가 그 사이트를 이용하는 과정에서 자체 약관과 개인정보 처리방침에 따라 통신합니다. 이는 확장 프로그램의 개발자 서버 전송과 구분됩니다.

## 5. 보관과 삭제

- Chrome 로컬 저장소의 데이터는 사용자가 초기화하거나 확장 프로그램을 삭제할 때까지 남을 수 있습니다.
- 현재 버전에서 누적 결과를 새로 만들려면 패널의 `초기화 후 수집` 기능을 사용할 수 있습니다.
- 모든 확장 로컬 데이터를 삭제하려면 Chrome 확장 관리 화면에서 확장 프로그램을 삭제합니다. 삭제 전 필요한 결과는 HTML 또는 CSV로 백업해야 합니다.
- 사용자가 생성한 HTML·CSV·PNG 파일은 확장 프로그램 삭제로 함께 삭제되지 않으며 사용자가 파일 시스템에서 직접 삭제해야 합니다.

## 6. 공유와 사람의 열람

개발자는 확장 프로그램을 통해 처리된 데이터를 자동으로 수신하거나 열람하지 않습니다. 사용자가 오류 문의를 위해 파일이나 화면을 직접 첨부한 경우에만 해당 문의 처리에 필요한 범위에서 확인합니다. 법령상 요구되는 경우를 제외하고 제3자에게 판매하거나 제공하지 않습니다.

## 7. 보안과 한계

확장 프로그램은 지원 사이트 하나로 실행 범위를 제한하고, 필요한 Chrome 권한만 요청하며, 전체 탭 캡처 fallback·HTML 스크립트 삽입·CSV 수식 실행 위험을 줄이는 검사를 적용합니다. 다만 사용자의 기기·Chrome 프로필·내보낸 파일에 접근할 수 있는 사람은 로컬 결과를 볼 수 있으므로 기기와 파일을 안전하게 관리해야 합니다.

## 8. Chrome 웹 스토어 사용자 데이터 정책 준수

이 확장 프로그램의 사용자 데이터 사용은 공개된 단일 목적을 제공하는 데 필요한 범위로 제한됩니다. Chrome 웹 스토어 사용자 데이터 정책과 Limited Use 요구사항을 준수하며, 공개한 목적 밖의 사용·전송·판매를 하지 않습니다.

## 9. 변경 안내

데이터 처리 방식이 변경되면 코드·스토어 개인정보 신고·이 방침을 함께 갱신하고, Chrome 정책이 요구하는 경우 변경 내용을 사용자에게 명확히 알리고 동의를 받습니다.
